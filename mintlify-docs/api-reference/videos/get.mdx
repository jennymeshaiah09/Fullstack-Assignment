## Get Video

Returns full metadata for a single video including its sensitivity analysis results.

**Requires authentication.** Users can only access their own videos. Admins can access any video.

---

### Path Parameters

| Parameter | Description |
|---|---|
| `id` | MongoDB `_id` of the video |

### Request

```http
GET /api/videos/69ccf0bd3f1a2b4c5d6e7f89
Authorization: Bearer <token>
```

---

```json
{
  "video": {

    "title": "My Video",

    "s3Url": "https://bucket.s3.region.amazonaws.com/videos/uuid.mp4",
    "thumbnailUrl": "https://bucket.s3.region.amazonaws.com/thumbnails/69ccf0bd.jpg",
    "fileSize": 98764321,
    "mimeType": "video/mp4",
    "duration": 0,
    "status": "flagged",
    "sensitivityScore": 85,
    "sensitivityDetails": {
      "violence": false,

      "hate": false
```

### Response `404 Not Found`

```json
{ "message": "Video not found" }
```

### Response `403 Forbidden`

```json
{ "message": "Not authorised to access this video" }
```

### Example

```bash cURL
curl http://localhost:5000/api/videos/69ccf0bd3f1a2b4c5d6e7f89 \
```
