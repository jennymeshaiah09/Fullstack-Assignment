## List Videos

Returns all videos belonging to the authenticated user, sorted newest first. Admins see only their own videos here — use the [Admin: All Videos](/api-reference/admin/all-videos) endpoint for cross-user access.

**Requires authentication.**

---

### Request

```http
GET /api/videos
Authorization: Bearer <token>
```

### Query Parameters

| Parameter | Values | Description |
|---|---|---|
| `status` | `pending` \| `processing` \| `safe` \| `flagged` | Filter by processing status |

```http
GET /api/videos?status=flagged
```

### Example

```bash cURL
# All videos
curl http://localhost:5000/api/videos \
  -H "Authorization: Bearer eyJhbGci..."

# Only flagged videos
curl "http://localhost:5000/api/videos?status=flagged" \
  -H "Authorization: Bearer eyJhbGci..."
```
