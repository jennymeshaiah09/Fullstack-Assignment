## What VidSense AI Does

When a user uploads a video:

<Steps>
  <Step title="Upload to AWS S3">
    The video is streamed directly into an S3 bucket with a UUID key.
  </Step>
  <Step title="Async AI Processing">
    Google Cloud Video Intelligence analyses every frame for adult content, violence, and hate speech — in the background.
  </Step>
  <Step title="Real-time Updates">
    Socket.io pushes live stage updates (Validating → Analysing → Classifying → Complete) to the browser.
  </Step>
  <Step title="Classification">
    The video is marked `safe` or `flagged` with a 0–95 sensitivity score and stored in MongoDB.
  </Step>
</Steps>

## Tech Stack at a Glance

| Layer | Technology |
|---|---|
| Backend API | Node.js + Express |
| Database | MongoDB Atlas (Mongoose) |
| File Storage | AWS S3 |
| AI Analysis | Google Cloud Video Intelligence |
| Real-time | Socket.io |
| Frontend | React 18 + Vite |
| Auth | JWT (jsonwebtoken + bcryptjs) |
